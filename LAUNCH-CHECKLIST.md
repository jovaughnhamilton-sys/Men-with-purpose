# Men of Purpose — $0-to-January Launch Checklist

## Do this week (no payment)
- [ ] Open the prototype on a computer or phone and read all seven sample devotionals.
- [ ] Confirm the brand name and publisher endorsement.
- [ ] Create a free GitHub repository and publish the site with GitHub Pages.
- [ ] Test the published HTTPS address on Android and iPhone.
- [ ] Ask five men for feedback: Is the text easy to read? Is the daily challenge useful? Would you return tomorrow?

## Before public promotion
- [ ] Complete and proofread all 40 devotionals.
- [ ] Have a trusted Christian leader review doctrinal accuracy and pastoral sensitivity.
- [ ] Verify NLT copyright permissions or use Scripture references with authorized external links.
- [ ] Write a privacy policy that accurately describes local-only journal storage and any future data collection.
- [ ] Add a contact/feedback method and accessibility improvements.

## December release readiness
- [ ] Verify Triple J's legal publisher details and store organization enrollment eligibility.
- [ ] Decide on native packaging and implement it; PWA alone is not guaranteed app-store compliant.
- [ ] Produce required screenshots, PNG icons, and app descriptions.
- [ ] Test Android and iOS builds on actual devices.
- [ ] Review current Google Play testing and Apple App Review requirements.

## January 2027, only when ready
- [ ] Pay Google Play and Apple developer fees if eligible.
- [ ] Complete verification, mandatory testing and privacy declarations.
- [ ] Submit apps for review. No guaranteed approval date.

**Financial rule:** Do not buy a domain, paid no-code plan, premium design assets, or developer membership before the beta is useful and the store packaging route is validated.
